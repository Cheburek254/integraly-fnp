Решите задачу самостоятельно, затем откройте подсказку или сверьте решение. В каждой задаче проверьте, по какому объекту идёт интегрирование и что означает элемент интеграла.

Задача 01 · Интегральная сумма

Оценка по четырём ячейкам

Для f(x,y)=x2+y на единичном квадрате постройте интегральную сумму по четырём равным ячейкам, используя их центры. Сравните её с точным значением.

Подсказка

Координаты центров принимают значения 1/4 и 3/4. Площадь каждой ячейки равна 1/4.

Решение

Среднее значение x2 по центрам равно (1/16+9/16)/2=5/16, а среднее значение y равно 1/2. Площадь квадрата равна 1, поэтому сумма равна 13/16. Точный интеграл равен 1/3+1/2=5/6, что больше суммы на 1/48.

Задача 02 · Двойной интеграл

Сечение меняет границу

Поменяйте порядок интегрирования в ∫01∫x22−xf(x,y)dydx. Затем найдите площадь области.

Подсказка

Для горизонтального сечения правую границу определяет меньшее из √y и 2−y. Найдите высоту их пересечения.

Решение

Проекция на ось y равна [0,2]. Правая граница равна √y при 0≤y≤1 и 2−y при 1≤y≤2. Левая граница всюду x=0.

∫01∫0√yf(x,y)dxdy+∫12∫02−yf(x,y)dxdy

Для площади берём f=1. Два слагаемых дают 2/3+1/2=7/6.

Задача 03 · Тройной интеграл

Масса тетраэдра

Найдите массу тела x,y,z≥0, x+y+z≤1 с объёмной плотностью ρ=z.

Подсказка

При фиксированном z сечение — прямоугольный треугольник с катетами длины 1−z.

Решение

Плотность постоянна на каждом горизонтальном сечении. Его площадь равна (1−z)2/2. Интегрируем произведение площади на плотность по высоте.

M=∫01z(1−z)2/2dz=(1/2−2/3+1/4)/2=1/24

Задача 04 · Системы координат

Одна точка, три записи

Запишите точку (0,−3,4) в цилиндрических и сферических координатах. Возьмите 0≤φ<2π.

Подсказка

Проекция на плоскость xy лежит на отрицательной оси y. Высота равна 4, расстояние от оси z равно 3.

Решение

Азимут равен 3π/2. Цилиндрические координаты (3,3π/2,4). В сферических ρ=√(9+16)=5, cosθ=4/5. Получаем (5,arccos(4/5),3π/2) в порядке (ρ,θ,φ).

Задача 05 · Якобиан

Площадь эллипса

Вычислите площадь эллипса x2/a2+y2/b2≤1 при a,b>0.

Подсказка

Возьмите x=arcosφ и y=brsinφ. Область параметров такая же, как у единичного круга.

Решение

Растяжения по двум осям дают множитель ab, а полярные координаты добавляют r. Поэтому |J|=abr.

A=∫02π∫01abrdrdφ=πab

Задача 06 · Криволинейный интеграл

Работа по двум путям

Для поля F=(−y,x) найдите работу из (0,0) в (1,1) по диагонали и по ломаной через (1,0).

Подсказка

Используйте −ydx+xdy. Для ломаной интегрируйте по каждому отрезку отдельно.

Решение

На диагонали x=y=t, поэтому −ydx+xdy=0. На первом отрезке ломаной y=0 и dy=0. На втором x=1 и dx=0, поэтому работа равна ∫01dy=1. Итоги по двум путям — 0 и 1.

Задача 07 · Поверхностный интеграл

Поток через наклонный треугольник

Найдите поток поля F=(0,0,2) через часть плоскости z=1−x−y в первом октанте. Выберите нормаль вниз.

Подсказка

Проекция на плоскость xy — треугольник x,y≥0, x+y≤1.

Решение

Векторный элемент при нормали вниз равен (−1,−1,−1)dxdy. Скалярное произведение с полем равно −2dxdy. Площадь проекции равна 1/2, поэтому поток равен −1.

Задача 08 · Теорема о потоке

Шесть граней одним интегралом

Найдите поток поля F=(x2,y2,z2) через замкнутую границу единичного куба с внешней нормалью.

Подсказка

Воспользуйтесь теоремой Остроградского — Гаусса. Каждая координата на единичном кубе имеет среднее значение 1/2.

Решение

divF=2x+2y+2z. Интеграл каждого слагаемого по единичному кубу равен 1. Внешний поток равен 3.
