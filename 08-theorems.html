Грин, Стокс и Гаусс

Три теоремы связывают интеграл по границе с интегралом по области, которую эта граница ограничивает. Начните с проверки типа интеграла и ориентации.

Теорема Грина. Контур и область на плоскости

Знак ∂ перед названием области означает её границу. Знак ∮ показывает, что путь замкнут. Интеграл поля вдоль замкнутого пути называют циркуляцией.

Пусть D — ограниченная плоская область с кусочно-гладкой границей, а P,Q имеют непрерывные частные производные в её окрестности. При положительном обходе область остаётся слева. Внешняя граница обходится против часовой стрелки, а границы отверстий — по часовой.

∮∂DPdx+Qdy=∬D(∂Q/∂x−∂P/∂y)dA

Пример. Для единичной окружности и поля F=(−y/2,x/2) подынтегральное выражение справа равно 1. Циркуляция при положительном обходе равна площади диска, то есть π.

Теорема Стокса. Контур и натянутая поверхность

Пусть S — ориентированная кусочно-гладкая поверхность с кусочно-гладкой границей, а поле F имеет непрерывные частные производные в окрестности S. Положительный обход согласован с нормалью по правилу правой руки. Для плоского диска с нормалью вверх это обход против часовой стрелки при взгляде сверху.

∮∂SF·dr=∬SrotF·ndS

Ротор поля F=(P,Q,R) равен (Ry−Qz,Pz−Rx,Qx−Py). По Стоксу циркуляцию можно считать через удобную поверхность с той же границей, если условия теоремы выполнены для этой поверхности.

Пример. Для F=(−y,x,z) имеем rotF=(0,0,2). На единичной окружности в плоскости z=0 с положительным обходом возьмём плоский диск и нормаль вверх. Циркуляция равна 2π.

Теорема Остроградского — Гаусса. Замкнутая поверхность и тело

Пусть T — ограниченное тело с кусочно-гладкой границей ∂T, а поле F=(P,Q,R) имеет непрерывные частные производные в окрестности тела. Нормаль направлена наружу.

∯∂TF·ndS=∭TdivFdV
divF=∂P/∂x+∂Q/∂y+∂R/∂z

Пример. Для поля F=(x,y,z) дивергенция равна 3. Поток через единичную сферу равен 3·4π/3=4π. На сфере поле совпадает с внешней единичной нормалью, поэтому напрямую получается её площадь, тоже 4π.

Как выбрать теорему

Что даноЧто можно вычислитьТеорема
Циркуляция по плоскому контуруДвойной интеграл по плоской областиГрина
Циркуляция по пространственному контуруПоток ротора через поверхность с этой границейСтокса
Поток через замкнутую поверхностьТройной интеграл от дивергенцииОстроградского — Гаусса

Самопроверка

Поток через куб

Найдите внешний поток F=(2x,3y,4z) через границу единичного куба.

Подсказка

Граница замкнута. Вычислите дивергенцию поля.

Решение

divF=2+3+4=9. Объём куба равен 1, поэтому поток равен 9.

Лекции О. П. Далевской · § 5.5 и § 5.7 · с. 48–55
