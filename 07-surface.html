Поверхностные интегралы

Поверхность можно разбить на маленькие почти плоские участки. Для площади нужна величина каждого участка, а для потока важна также сторона поверхности.

Первый род. Площадь и масса

Например, у графика z=x+y можно выбирать x и y, а высота определяется формулой. В общем случае два числа u,v задают точку поверхности r(u,v). Два параметра позволяют перемещаться по поверхности в двух направлениях.

Пусть r(u,v) — регулярная параметризация поверхности, которая покрывает её один раз, за исключением возможных швов или границ. Малый прямоугольник параметров переходит в участок, площадь которого приближённо равна площади параллелограмма на векторах rudu и rvdv.

Символ × обозначает векторное произведение. Его результат перпендикулярен обоим исходным векторам, а его длина равна площади натянутого на них параллелограмма. Поэтому:

dS=|ru×rv|dudv
∬SfdS=∬Df(r(u,v))|ru×rv|dudv

При f=1 получаем площадь поверхности. Для поверхностной плотности получаем массу. Для графика z=g(x,y) множитель площади равен:

dS=√(1+gx2+gy2)dxdy

Второй род. Поток через выбранную сторону

Чтобы найти поток поля F, умножьте нормальную составляющую F·n на элемент площади. Здесь n — единичная нормаль, согласованная с выбранной ориентацией поверхности.

Φ=∬SF·ndS

Для графика z=g(x,y) нормаль вверх направлена как (−gx,−gy,1). Длина этого вектора уже равна множителю площади, поэтому можно сразу использовать векторный элемент:

ndS=(−gx,−gy,1)dxdy

Для ориентации вниз умножьте весь вектор на −1. Для замкнутой поверхности обычно выбирают внешнюю нормаль.

Разбор

Один график, площадь и поток

Рассмотрим z=x+y над единичным квадратом D. Обе частные производные равны 1, так что элемент площади равен √3dxdy.

A=∬D√3dxdy=√3

Найдём поток поля F=(0,0,z) вверх. Подставляем в поле z=x+y и берём скалярное произведение с (−1,−1,1).

Φ=∬D(x+y)dxdy=1/2+1/2=1

Для нормали вниз поток равен −1.

Направление поля на поверхности

Касательная составляющая поля даёт нулевой вклад в поток. Знак потока определяет составляющая вдоль выбранной нормали.

Самопроверка

Поток через горизонтальный диск

Найдите поток F=(0,0,3) через единичный диск в плоскости z=0 при нормали вниз.

Подсказка

Единичная нормаль равна (0,0,−1).

Решение

Нормальная составляющая равна −3. Площадь диска равна π, поток равен −3π.

Лекции О. П. Далевской · § 5.6 · с. 50–53
